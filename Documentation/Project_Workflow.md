# Project Workflow

## E-commerce Conversion Funnel Analysis

This project follows an end-to-end data analytics workflow.

### Step 1 — Data Source

Google Analytics 4 public e-commerce sample dataset was used as the source data.

### Step 2 — BigQuery

The raw event data was analyzed using BigQuery SQL.

Main funnel stages:

Visit → Product View → Add to Cart → Purchase

SQL analysis included:

- Funnel data
- Funnel metrics
- Bottleneck analysis
- Monthly funnel analysis
- Channel analysis
- Device analysis
- KPI summary

### Step 3 — Python / Pandas

Python was used for exploratory data analysis.

Analysis included:

- Dataset exploration
- Monthly conversion analysis
- Stage-wise conversion rates
- Month-on-Month conversion change
- Highest conversion month
- Lowest conversion month
- Monthly trend visualization
- Final analytical insights

### Step 4 — Power BI

The final dashboard was created in Power BI.

The dashboard contains three main visuals:

1. Conversion Funnel
2. Funnel Stage Conversion / Drop-off
3. Monthly Visitors vs Purchases

### Step 5 — Business Insights

The analysis was converted into business-focused insights and recommendations.

### Step 6 — GitHub

The final project contains:

- SQL scripts
- Python analysis
- Power BI dashboard
- Documentation
- README
