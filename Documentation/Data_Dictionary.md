# Data Dictionary

## E-commerce Conversion Funnel

The analysis follows this funnel:

Visit → Product View → Add to Cart → Purchase

| Column | Description |
|---|---|
| month | Month of the analysis period |
| visitors | Users reaching the visit/session stage |
| product_views | Users viewing a product |
| add_to_cart | Users adding a product to cart |
| purchases | Users completing a purchase |
| visit_to_product_conversion | Visit → Product View conversion rate |
| product_to_cart_conversion | Product View → Add to Cart conversion rate |
| cart_to_purchase_conversion | Add to Cart → Purchase conversion rate |
| overall_conversion | Visit → Purchase conversion rate |
| MoM_Conversion_Change | Month-on-Month change in overall conversion |

## Funnel Metrics

- Visit → Product View
- Product View → Add to Cart
- Add to Cart → Purchase
- Overall Visit → Purchase
